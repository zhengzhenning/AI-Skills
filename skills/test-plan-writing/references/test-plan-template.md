### ⏳ TC-GRAY-001：灰度用户正确登录

- 🎯 测试场景：[正常] 验证灰度目标用户登录后命中灰度版本。
- 🧰 前置条件：测试服务可用；当前会话未登录；用户已加入 `灰度组-A`；灰度开关开启。
- 🗃️ 测试数据：执行后移除测试用户的灰度标签。

  ```json
  {
    "account": "gray-tester@example.com",
    "password": "***安全存储引用***",
    "grayTag": "灰度组-A"
  }
  ```

- 🧭 测试步骤：
  1. 确认测试用户带有 `灰度组-A` 标签。
  2. 调用 `POST /api/login`，填写正确密码。
  3. 记录响应体、登录状态和实际命中版本。
- 💡 测试预期：用户登录成功并命中灰度版本。

