# 规模、复杂度与拆解

默认阈值是触发分析的信号，不是跨语言硬门禁：普通方法 40 行、复杂方法 60 行、类 300 行、参数 5 个、嵌套 3 层、圈复杂度 10。生成代码、DTO、迁移脚本和测试夹具可由项目明确豁免。

超限时记录实际指标，按职责拆分：纯计算 → 校验 → 查询 → 业务规则 → 持久化/外部调用，并保留线性的业务编排入口。禁止仅为降行数切出一行方法、引入模糊工具类、类爆炸，或破坏事务和性能边界。

响应式关注异步阶段、嵌套 `compose/flatMap`、阻塞事件循环和重复副作用；Go 关注函数复杂度、文件职责和并发状态；React 关注组件、Hook、Effect 和状态边界。
